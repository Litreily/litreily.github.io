用 Codex 做一个东方美人全栈导演 Skill

Created2026-06-08|Updated2026-06-08|AI
|Post Views:

最近我在做一个很有意思的小项目：把「东方美人」这个 AI 生图方向，整理成一个可以被 Codex 调用的 Skill。

它不是一份简单的 Prompt 合集，也不是把几个风格词堆在一起。我的目标是让 Codex 像一个全栈导演一样工作：理解用户想看的美，推导风格，控制画面，生成提示词，必要时做安全改写，最后还能把图片和过程沉淀成博客。

项目地址在这里：

https://github.com/Litreily/codex-skill-eastern-beauty-director

先看几张已经用这个 Skill 跑出来的图：

如果你也在探索 AI 绘画、人物写真、国风审美、Codex Skill 或自动化内容生产，希望这篇文章能给你一些参考。

1. 我为什么要做这个 Skill

AI 生图最开始很容易陷入一个误区：以为只要把关键词写得足够多，图就会变好。

但我反复测试后发现，真正决定画面质量的不是词多，而是导演判断。

比如同样是「东方美人」，它可以是：

  • 唐宫花泉里的高贵仪式感
  • 江南雨巷里的含蓄电影感
  • 敦煌风沙里的神性与壁画感
  • 现代城市里的甜系生活感
  • 青瓷、宋韵、昆曲、旗袍、新中式、东方赛博等更多方向

这些风格看起来都属于东方审美，但它们需要完全不同的场景、服装、镜头、光线和负面约束。

如果每次都从零写 Prompt，很快就会变成重复劳动。更麻烦的是，古风和东方幻想图特别容易失控：金色乱飞、珠宝乱飞、披帛乱飞、粒子乱飞，最后变成很热闹但没有高级感的 AI 壁纸。

所以我想做的不是“收藏几个好词”，而是把这些判断沉淀成一个可调用的导演系统。

2. 它解决的核心问题

这个 Skill 主要解决四个问题。

第一，让小白不用研究复杂 Prompt。

用户只需要给出结构化参数，例如：

技能: 古典东方美人
风格: 唐宫花泉仪式
气质: 高贵大气，柔美
场景: 唐代宫廷花泉池畔，花瓣倒影池，纱幔，烛台，香雾
服装: 浅金与暖玉白层叠唐风礼服
动作: 一手扶纱幔，一手持金碗，将牡丹花瓣轻轻洒向水面
构图: 全身
生成: 是

Codex 会负责把这些参数扩展成完整生图提示词。

第二，让风格不再靠碰运气。

Skill 里会区分不同路线：古典东方美人、东方幻想古风、现代东方审美、甜系纯欲生活写真等。每条路线都有自己的审美目标、镜头语言、服装逻辑、场景边界和负面提示。

第三，让敏感内容自动做最小改写。

比如用户说“泡花浴池”“浴裙”“洗浴柔美”，这类词在一些生图工具里可能比较敏感。一个好的 Skill 不应该直接把用户需求推翻，也不应该把画面改成完全无关的内容。

更合理的做法是：保留核心元素，把表达转成更稳的版本。

例如：

泡花浴池 -> 唐宫花泉池畔
洗浴 -> 花泉仪式 / 洒花入水 / 香雾中的仪式瞬间
浴裙 -> 覆身不透明丝绸浴礼服 / 唐风层叠礼服

这样画面的水、花、宫廷、柔美、仪式感都还在，但表达更克制，也更容易通过模型安全策略。

第四，让生图结果可以沉淀。

我后来把它接到了博客发布流程里：每天可以随机探索四张不同风格的东方美人图，按日期归档，自动写成 Hexo 博客并部署。

这就不只是“生成一张图”，而是把审美探索变成一个长期项目。

3. 我对「东方美人」的理解

这个项目最核心的主题始终是东方美人。

但我不希望它被限制成一种脸、一种服装、一种古风模板。

我更希望它能展示不同类型的美：

  • 柔美：线条、姿态、神态都温和流动
  • 妩媚：有成熟吸引力，但不粗暴、不擦边
  • 高贵：服饰、姿态和空间都有仪式感
  • 优雅：少一点堆砌，多一点留白
  • 神性：像壁画、神女、祭司、梦境里的角色
  • 生活感：现代女生也可以属于东方审美

所以这个 Skill 不是“固定一个角色换衣服”，而是围绕东方美人的主体，持续探索不同风格的可能性。

4. 一个重要规则：先看人，再看故事，最后看装饰

做东方幻想图时，我最想固化的一条规则是：

先看脸和眼神
再看故事瞬间
最后看服装、珠宝、披帛、背景

很多 AI 古风图的问题，不是细节不够，而是细节太多。

红色、金色、珠宝、烛火、纱幔、壁画、粒子、刺绣，全都是高频元素。如果不控制密度，画面会很快变成视觉噪音。

所以我给 Skill 增加了一套东方审美的“去噪规则”：

subject-first composition
clean face priority
controlled ornament density
one wow device only
preserve negative space
premium color harmony
less but better

翻译成人话就是：

不要让珠宝和光效抢走主角。每张图只保留一个最重要的视觉记忆点。

5. 甜系纯欲为什么也放进东方美人系列

这个项目里还有一个比较特别的分支：甜系纯欲生活写真。

一开始它看起来和古风、敦煌、唐宫不是一类东西。但测试下来我发现，它其实补足了东方美人的现代生活面。

我对这个方向的定义不是“露肤”，也不是“网红性感”，而是：

真实感 + 女性魅力 + 恋爱感 + 故事瞬间 + 自然纯欲

用户可以这样调用：

技能: 甜系纯欲生活写真
人脸风格: 邻家女孩
场景: 自助洗衣房
穿搭: 宽松白T，牛仔短裙，帆布鞋
故事瞬间: 她正把衣服从烘干机里抱出来，发现你在门口等她，忍不住笑了一下
构图: 9比16，上半身
生成: 是

它和古典路线的共同点是：人物始终是主体，故事瞬间比摆拍更重要，吸引力来自真实感和画面关系，而不是单纯堆性感元素。

7. 它和普通 Prompt 项目有什么不同

普通 Prompt 项目通常提供一批现成模板。

这个项目更像一个导演系统：

  • 它会根据用户参数推导完整画面
  • 它会判断哪个元素应该优先
  • 它会控制风格不要跑偏
  • 它会在敏感表达上做最小改写
  • 它会补充镜头、光线、材质、负面提示
  • 它还可以把结果写成博客，形成长期作品集

对我来说，真正有价值的不是某一条 Prompt，而是这个系统背后的审美判断。

8. 项目当前支持的方向

目前它主要覆盖这些方向：

  • 古典东方美人
  • 东方幻想古风
  • 现代东方审美
  • 新中式时装与杂志感
  • 甜系纯欲生活写真
  • 唐宫、宋韵、江南、敦煌、青瓷、昆曲、旗袍、东方赛博等扩展路线

后续我还想继续探索更多不那么常见的方向，比如：

  • 东方珠宝大片
  • 博物馆文物拟人
  • 山海经异兽神女
  • 民国电影感
  • 东方海岛度假
  • 新中式都市通勤
  • 水墨实验影像
  • 古典舞台与戏曲美学

只要东方美人这个主体不变，风格可以不断打开。

9. 写在最后

我做这个项目，最开始只是为了让 AI 生图更稳定一点。

但做着做着，我发现它其实是在整理一套审美工作流：如何把模糊的美感偏好，变成可以调用、可以验证、可以迭代的系统。

这也是 Codex Skill 很有意思的地方。它不只是让 AI “知道一些提示词”，而是让 AI 在一个具体领域里逐渐形成工作方法。
